# Notebooks

This folder contains the Jupyter notebooks used in this project.

## Workflow

1. `01_preprocessing.ipynb` – Data preprocessing and harmonization.
2. `02_feature_extraction.ipynb` – HRV feature extraction and feature engineering.
3. `03_training_evaluation.ipynb` – Model training and cross-dataset evaluation.
4. `04_permutation_importance.ipynb` – Feature importance analysis using permutation importance.
5. `05_statistical_tests.ipynb` – Statistical analysis of model performance.
